## ⚠️ Сервер 37.151.92.25 не подходит — отложен

Сервер физически не может запустить TensorFlow: CPU — старый эмулированный "QEMU Virtual CPU
version 2.5" без AVX2 (`Illegal instruction (core dumped)` при `import tensorflow`, даже после
починки отдельной проблемы с numpy через `numpy<2.4`). Это ограничение хостинга/гипервизора, не
нашего кода — подтверждено тестами:
- `import numpy` — падал с `RuntimeError: X86_V2`, чинится через `numpy<2.4`
- `import tensorflow` — падает с `Illegal instruction`, TF официально требует AVX2, нечинибельно на уровне pip

Решение отложено — этот сервер не используем для деплоя. Понадобится другой VDS/хостинг с
нормальным CPU (поддержка AVX2) для реального продакшен-деплоя в будущем.
